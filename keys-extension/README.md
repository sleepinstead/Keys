# Keys browser extension

Fills your logins on websites and offers to save new ones, for Chrome, Edge, Brave and other Chromium browsers (Chrome 120+). It talks to whichever Keys is running on this computer (Mac or Windows app, or keys-web) at 127.0.0.1:5174 and keeps no passwords itself.

Try it: open `chrome://extensions`, turn on **Developer mode**, **Load unpacked** and pick this folder. Releases: bump `manifest.json`'s version; the Mac and Windows release scripts attach a zip of this folder.
